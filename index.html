Capabilities

What this project demonstrates

🧪

Continuous Integration

Every push to the main branch automatically installs dependencies and executes the Python test suite using PyTest.

🚀

Continuous Deployment

Deployment runs only after CI succeeds. The website is automatically published through GitHub Pages.

🛡️

Failure Protection

If automated tests fail, the deployment stage is skipped. This prevents defective changes from reaching production.

🔁

Automated Workflow

The entire process runs through GitHub Actions without requiring manual deployment steps.

📊

Pipeline Monitoring

Workflow execution, test results, deployment status and artifacts can be monitored directly from GitHub Actions.

🌐

Live Production

The final application is available publicly through GitHub Pages after successful deployment.
